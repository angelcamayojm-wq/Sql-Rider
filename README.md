## 📊 Modelo de Base de Datos y Relaciones SQL

El sistema gestiona de manera eficiente las 4 relaciones principales de la base de datos:

| Icono | Entidad / Módulo | Tipo de Relación SQL | Descripción |
| :---: | :--- | :---: | :--- |
| 🏢 | **Empresas** | **Entidad Principal** | Registro fiscal y administrativo de la empresa operadora. |
| 👨‍✈️ | **Conductores** | **1 a N (One-to-Many)** | Una empresa puede contratar múltiples conductores. |
| 🪪 | **Licencias** | **1 a 1 (One-to-One)** | Cada conductor posee de forma exclusiva una licencia activa. |
| 🗺️ | **Rutas** | **N a M (Many-to-Many)** | Múltiples conductores cubren variadas rutas intermunicipales. |
